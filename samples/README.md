# 虚构演示数据说明

本目录内所有 JD、姓名、简历内容、联系方式、公司、项目与业绩数字均用于虚构演示，不是真实候选人资料。PDF、DOCX、TXT 以及扫描件样例均遵循此说明；`scripts/make_*` 是相应样例的生成脚本。

`docs/` 中关联这些候选人的截图、JSON 与 CSV 也是虚构数据的演示记录。简历中的提升比例等数字属于虚构候选人的描述，不是本系统经过测量的效果指标。

推荐从 `credibility/jd_backend.txt` 和两份明确标记为虚构的测试甲、测试乙简历开始，按根目录 README 的演示路径操作。旧样例和历史截图的分数不代表当前版本输出，也不是招聘准确率评估。

请勿将真实候选人的简历、导出文件、数据库或模型密钥提交到本仓库。
