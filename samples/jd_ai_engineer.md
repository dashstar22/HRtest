岗位名称：高级 AI 应用工程师
用人部门：智能应用中心
工作地点：上海 / 杭州
薪资范围：35K-55K · 15 薪

岗位职责：
1. 负责公司 AI 应用产品的后端架构设计与核心功能开发；
2. 基于大语言模型（LLM）搭建简历解析、智能问答、内容审核等业务链路；
3. 设计并优化 RAG 检索增强方案，提升企业知识库问答的准确率；
4. 与产品、算法团队协作，推动 AI 能力在招聘、客服等场景落地；
5. 参与技术方案评审，指导初级工程师成长。

任职要求：
1. 本科及以上学历，计算机、软件工程或相关专业；
2. 5 年以上后端开发经验，其中 2 年以上 Python 工程经验；
3. 精通 Python，熟悉 FastAPI 或 Django 等主流 Web 框架；
4. 熟悉 PostgreSQL / MySQL，具备 SQL 优化能力；
5. 熟悉 Redis、消息队列，了解 Docker 与 Kubernetes；
6. 有大模型应用开发经验（Prompt Engineering、RAG、Agent）者优先；
7. 有向量数据库（Milvus / pgvector / FAISS）实践经验者优先；
8. 具备良好的沟通能力与团队协作意识，能承担一定压力。
